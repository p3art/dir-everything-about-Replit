Here is the information regarding storage for your Core plan:

The **Replit Core plan typically includes 50 GiB of Workspace Storage per Repl.
This storage is for your code, installed packages, and temporary files within the development container. The 50 GiB limit is usually fixed for the Core tier.

Object Storage (Buckets):
If you need to store large files (like datasets, images, or backups), Replit offers **Object Storage** which is billed based on usage. * **Cost:** $0.04 per GiB per month.
For $6.00/month, you could theoretically store 150 GiB of Object Storage data ($6.00 / $0.04), which is a significant amount.

How Replit's storage limits work for the Core plan.

1. For Replit Core plan, you have unlimited private Repls.

  • 752 Apps: You can continue creating new apps. There is no hard limit on the number of apps you can own.
  • 50 GiB Limit: This limit applies per Repl (App), not to your entire account.
    Each individual app can be up to 50 GiB.
    You don't need to worry about the total size of all 752 apps added together.

2. The "$6 Extra" Option

  • Object Storage costs roughly $0.04 - $0.05 per GiB.
  • If you spent $6.00 purely on Object Storage, you would get roughly 120 - 150 GiB of space for storing large files (images, datasets, backups) that can be shared across your apps.

Suggestion

Since you want to develop more apps:

  1. Just keep building: You likely don't need to pay anything extra. Your Core plan already allows for unlimited apps.
  1. Use Object Storage: If you have apps with huge files, move those files to an Object Storage bucket (using the Bucket icon in the sidebar) to keep your workspace light.
